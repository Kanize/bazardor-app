# 🛒 বাজার দর | BazarDor

### 🇧🇩 Today's Market Prices at a Glance

BazarDor is a Bangla-language web application that helps users explore daily market prices of essential products in Bangladesh. Users can browse products by category, view detailed product information, and compare price changes over time.

## 🛠️ Technologies Used

- ⚛️ **Next.js** — React framework for building web applications
- ⚛️ **React** — Component-based user interfaces
- 📘 **TypeScript** — Type-safe JavaScript development
- 🎨 **Tailwind CSS** — Responsive and modern styling
- 🌼 **daisyUI** — Ready-to-use UI components
- 🔐 **Better Auth** — User authentication and session management
- 🔗 **REST API** — Product and category data fetching

## ✨ Key Features

- 💰 **Daily Market Prices** — Explore the latest available prices of essential products.
- 🗂️ **Category-Based Browsing** — Find products easily through organized categories.
- 📈 **Price Change Tracking** — Compare prices with previous days, weeks, and months.
- 🔎 **Product Details** — View product information, price summaries, and price comparisons.
- 🔒 **User Authentication** — Sign up, sign in, and access protected pages.
